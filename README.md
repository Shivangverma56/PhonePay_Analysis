📊 PhonePe Payment Insights Dashboard | Power BI

📌 Project Overview
The PhonePe Payment Insights Dashboard is an interactive business intelligence project developed using Microsoft Power BI. It analyzes digital payment transactions, transaction values, customer demographics, service categories, and payment performance to generate meaningful business insights through data visualization.

🎯 Project Objectives
- Analyze transaction volume and transaction value trends.
- Monitor successful, pending, and failed payment statuses.
- Understand customer demographics and age-segment contributions.
- Compare transaction values across different service categories.
- Identify top customers based on transaction value.
- Analyze weekday versus weekend payment activity.

🛠️ Tools & Technologies
- **Power BI** – Dashboard development and visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – KPI calculations and analytical measures
- **Data Analytics** – Trend analysis and business insights

📈 Dashboard Features
- **KPI Cards:** Total Transactions, Total Transaction Value, Unique Users, and Successful Rate.
- **Payment Status Analysis:** Interactive filtering by successful, pending, and failed transactions.
- **Transaction Trends:** Monthly analysis of transaction volume and value.
- **Age Segment Analysis:** Visualizes the contribution of different customer age groups.
- **Service-Wise Analysis:** Compares loans, insurance, money transfers, and recharge bills.
- **Top 5 Customers:** Highlights customers with the highest transaction values.
- **Usage Analysis:** Compares weekday and weekend transaction activity.
- **Interactive Filters:** Enables users to explore data by month and payment status.

💡 Key Business Insights
- Transaction volume and transaction value can be monitored across monthly periods.
- Service-wise analysis helps identify categories contributing the most transaction value.
- Customer segmentation provides insights into demographic contributions.
- Top-customer analysis highlights high-value customers.
- Weekday and weekend comparisons help identify payment usage patterns.
- Payment status analysis helps monitor transaction success and failure trends.

🚀 How to Use
1. Clone or download this repository.
2. Download and install Microsoft Power BI Desktop.
3. Open the `.pbix` file in Power BI Desktop.
4. Refresh the data if the source dataset is available and configured.
5. Explore the dashboard using the interactive filters and visualizations.
